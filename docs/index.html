七个包，各司其职

core
类型安全领域模型 + 阅读时长估算
dsl
模块序列编排规则（信息类型交替）
gates
事实门禁 + 验收状态机 + 审计记录
links
链接编排 + UTM 五参数 builder
render
HTML/Markdown/text/JSON 渲染 + 自包含 JSON 解析
qa
发布前检查 + 系列多样性 + 分级 checklist
retro
复盘记录 + 可配置规则表 → 下一期

对标其他语言生态

参考库我们借鉴了什么区别
Zod / Valibot (TS)类型安全运行时校验它们是通用 schema，我们是多期内容垂直领域模型
Pydantic (Python)数据模型 + 校验分离通用 vs 内置内容领域逻辑（Block/Claim/Link）
react-email (TS)邮件组件化结构它们管单封渲染，我们管多期编排与门禁
Contentful / Sanity (SaaS)内容模型 + 工作流状态机云端 SaaS vs 纯本地 WASM 可分发开源库
