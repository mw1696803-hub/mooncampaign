它在生态里的位置

MoonBit 已有 HTML 解析器、模板引擎、JSON 工具，但缺一个标准实现：MIME 消息构建。任何需要生成邮件字节流的项目都在重复实现协议编解码。mooncampaign/mime 补上这一层。

SMTP · ESP · Wasm

实现的标准

RFC内容状态
RFC 5322Internet Message Format — headers、折叠、日期格式✅
RFC 2045MIME Part One — Content-Transfer-Encoding✅ base64 + quoted-printable
RFC 2046MIME Part Two — multipart 边界与嵌套✅ alternative + mixed
RFC 2047MIME Part Three — 非 ASCII header 编码✅ encoded-word (B)
RFC 4648Base64 字母表✅
